Movie Management System je Go projekat koji demonstrira rad sa CRUD operacijama, pretragom i filtriranjem filmova, kao i preuzimanje podataka sa eksternih API-ja koristeći gorutine za konkurentnu obradu.
Projekat koristi MySQL bazu podataka za skladištenje informacija o filmovima i omogućava kreiranje, čitanje, ažuriranje i brisanje filmova, kao i pretragu po naslovu, žanru, režiseru i godini.
Cilj projekta je da prikaže praktičnu primenu Go programskog jezika.
